# Reversible mannequin trial

Full site backup before this experiment:
`/Users/marcfacchinetti/Downloads/salomon-elements-v2-tenues-backup-avant-mannequin-2026-10-29`

The trial changes only the dressed mannequin's head and exposed limbs. Garments, their positions, prices and animations are unchanged.

- Default: refined mannequin.
- Add `?mannequin=original` to index.html or the site URL to view the original mannequin.
- Permanent rollback: set `mannequinTest: false` in js/app.js.

The original silhouette.svg and legs.svg have not been modified.
